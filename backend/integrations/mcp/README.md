# MCP 工具边界

Gateway 按角色白名单选择 MCP 工具。工具的原始参数规则会保留给模型；服务端补上患者编号、确认状态等字段后，再按 MCP 发布的完整 JSON Schema 校验，校验失败就不会发起远程调用。schema 只允许引用自身定义，不会为了校验而访问外部地址。

FHIR 单条读取会核对资源类型、资源 ID 和患者归属。FHIR 搜索会逐条核对返回的资源类型和患者归属；格式不对或混入其他患者资料时，整次调用失败，不把结果交给 Agent。

患者资料中的文字仍作为不可信资料交给模型阅读。医疗确认和写入确认由 Gateway 流程及 FHIR 服务端判断，不从工具返回文字或模型自由文本中推断。
